# Security

owlit keeps API keys and publisher sign-ins on your Mac, runs coding agents on your files, and can share a
doc by link. If you find a way for any of that to leak or be misused, please report it privately: on
GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public
issue.

Fixes go into the latest release only; there are no older versions to patch.
